# 魔族小窝网站计划（可修改）

> 版本：2026-09-21 草案  
> 这份文档用于一起改想法。写在「待你决定」里的内容先不当作最终需求。

## 1. 这是什么网站

网站暂定名为 **魔族小窝**。

这里是魔王和小魔王平时能互相留东西、接着说话、慢慢存下这一年的地方。小魔丸住在小窝里，负责带路、回答问题、偶尔捣乱一点点。

网站要完成三件事：

1. 两个人随时能给对方留一句话、一段语音、一张照片。
2. 两个人能围绕同一件小事接着聊，不会聊着聊着就找不到前因后果。
3. 需要查问题、讲题或捋思路时，可以喊小魔丸出来帮忙。

### 当前角色

| 角色 | 是谁 | 在网站里做什么 |
|---|---|---|
| 大魔王 | 刘唱 | 发起、回复、留下一天里想分享的事 |
| 小魔王 | 思怡 | 发起、回复、留下一天里想分享的事 |
| 小魔丸 | 奶油白、粉色小角的小怪兽 | 迎接、传话提示、问答助手 |

小魔丸说的话和真人留言要分得清楚。它不替任何一方回复，也不假装谁在线。

## 2. 保留和调整

### 保留

- 留言板：文字、图片、语音、回复关系都保留。
- 纪念日：保留首页、七夕和原有照片、翻页、信件封存。
- 小魔丸欢迎动画：保留透明角色、跳过、重播和减少动态效果支持。

### 调整

- 「魔丸小助手」改名为「小魔丸问答」。
- 小魔丸问答不再只回答上海、同济和通勤；改成通用问答，重点支持学习、生活和临时查证。
- 上海攻略继续收起，代码和内容保留，暂时不放进主导航和首页。
- 首页从工具入口改成魔族小窝的共同据点。

## 4. 首页：魔族小窝

### 想让人一打开就看到什么

1. 对方有没有留新东西。
2. 你们最近共同写的是哪一页。
3. 有没有一件已经说好的小事。

### 场景

首页是一间小屋：书桌、信箱、纪念柜和小魔丸。电脑上可以看完整场景；手机上按纵向顺序呈现，每一处都有明确文字入口。

| 物件 | 打开什么 | 有内容时的变化 |
|---|---|---|
| 书桌和本子 | 第一年 | 展示最近一页的标题或对方刚补上的一句话 |
| 门边信箱 | 留言板 | 有新内容时露出一角信纸，小魔丸说「有你的信！」 |
| 纪念柜和相册 | 纪念日 | 显示最近的一张纪念卡 |
| 小魔丸 | 小魔丸问答 | 进入聊天页或打开一个简短提问框 |

首页不显示「已读」「对方在线」「多久没有回复」之类的内容。新内容只表示有内容到了，不催促谁马上回。

### 首页空白状态

小魔丸抱着本子坐在书桌边，给一个轻入口：

> 今天想留点什么？

按钮：留句话、拍张照片、去问小魔丸。

## 5. 第四年：双人魔族手账

### 这页要解决什么

复读这一年会有题目、考试和累的时候，也会有晚饭、吐槽、好笑的小事。第四年把这些放在同一本手账里，让两个人能围绕一件具体的事继续说话。

### 一页手账的结构

每页有：

- 标题：双方都能写。
- 大魔王的一半：文字、图片或语音。
- 小魔王的一半：文字、图片或语音。
- 页内回复：围绕这一页继续聊天。
- 可选操作：问小魔丸、发到留言板、收进纪念日。

任何一人都能先开一页。另一半什么时候补都行；没有完成率、连续天数和截止时间。

### 可以点的开场题目

这些只是帮人开始写，点开后可以改掉：

- 给你看看我现在的桌子。
- 拍张现在看到的天空。
- 今天有件事想吐槽。
- 终于把这个搞定了。
- 这首歌你听一下。
- 下次见面想吃什么？

### 在复读这一年里怎么用

- 思怡贴一道终于做出来的题，大魔王回一句自己的近况或看法。
- 思怡考完心里乱，只写「今天不太想说」，魔王可以只回一句，不逼她展开。
- 两个人各发一张当天的照片，拼成一页。
- 一页后来变得重要，再收进纪念日。

### 一起做的小约定

手账页可以发起一件很小的事：

> 周六晚上，一人挑一首歌/一部电影

> 考完那天，去吃上次说的那家店/去某个景点

对方可以发布评论，打勾勾

双方都打勾后，首页书桌旁显示这件小约定。做完后可以补一张照片或一句话。第一版不做自动提醒。

## 6. 留言板：继续说下去的地方

### 现有能力

当前留言板已经支持：

- 大魔王 / 小魔王署名。（目前是“思怡”，我觉得叫“小魔王”会更好）
- 文字、图片和语音。
- 回复某条留言，形成上下文。
- 服务器保存，刷新后仍能找到。

### 改造内容

手账和问答页能生成一条“待发送留言”，用户确认、编辑后才真的发送。

留言上显示出处，例如：

> 关于「给你看看我现在的桌子」

点出处能回到原来的手账页或问答页。原页面下方也显示同一条回复，不复制出两套聊天记录。

### 页面文案

| 场景 | 文案 |
|---|---|
| 新留言 | 有你的信！ |
| 图片按钮 | 给你看看我这边 |
| 回复按钮 | 我有话要说 |
| 发出成功 | 发过去啦 |
| 发送失败 | 哎呀，网络开小差了，再试一下？ |

## 7. 小魔丸问答

### 它能做什么

- 讲题、解释学习方法、梳理思路。
- 回答一般生活问题。
- 对需要最新信息的问题进行实际查询，并展示可打开的来源。
- 没有查准时直接说明，不编答案。

### 它不做什么

- 代替魔王写给小魔王的内容。
- 自动把对话发给对方。
- 把临时问题硬拗成学习计划。
- 假装自己知道没有来源的信息。

需要调整什么

- 当前是基于通勤等做的规则，全面调整为更灵活的问答助手

### 页面和语气

标题暂定：**小魔丸，帮我看看这个事儿～**

输入框示例：

> 魔丸，你帮我看看这题？

> 帮我参考一下这个事儿

> 这家店现在还开着吗？

回答默认先给重点。需要更多时，用户继续问。可以选一段点击「给魔王看看」或「给小魔王看看」，进入留言草稿；内容不会自动分享。

小魔丸的口吻示例：

> 你错在这一步哦，你知道为啥嘛？

> 这儿我漏看了一个条件，重新来哈。

> 这个题目你还要细致理解哈

### 技术调整

当前问答后台仍固定在上海、同济和通勤问题。改造时需要：

1. 换掉上海专属系统提示词、快捷问题和固定攻略卡。
2. 保留 DeepSeek 调用、联网查询和来源展示。
3. 为“从手账带入问题”和“发给对方看看”增加可确认的草稿流程。
4. 图片解题在确认模型能稳定读取题目后再开放；第一版先支持文字输入。

## 8. 纪念日

七夕保持独立的银河视觉、照片、信件和封存效果。

新的纪念日有两种来源：

1. 直接新建：填写日期、标题、封面和想留的话。
2. 从手账页收进来：先选一页，再编辑纪念日信息并确认创建。

纪念日页应保留通往原手账页和相关留言的入口。普通手账不会自动成为纪念日。

## 9. 小魔丸在各处的样子

| 页面 | 动作 |
|---|---|
| 首页 | 从书桌后探头、抱着牌子迎接 |
| 有新留言 | 抱信、轻轻晃一下 |
| 第四年 | 趴在本子边、从书后探头 |
| 问答 | 翻书、低头想一会儿 |
| 约定完成 | 跳一下 |
| 纪念日 | 抱着相册坐着 |

动作对应实际状态。所有动画短、可以跳过；开启减少动态效果时显示静态姿势。

## 10. 视觉与文案标准

### 视觉

- 主色：奶油白、烟紫、莓粉；少量旧金色点缀。
- 常用元素：小角、圆形族徽、手绘星星、书本、信纸、相册。
- 第四年偏晚自习后的桌面感：台灯、卷子边缘、铅笔字、被折过的纸条。
- 长留言、问答和表单使用清楚的正文排版，保证手机上容易读。

### 文案

所有文案按“真的会对对方说的话”来写。可以开玩笑，也可以只说一件小事。不要写成客服、广告或模板情话。

推荐：

- 嘿，有你的信！
- 给你看看我这边。
- 我也有话要说。
- 周六一起XXX？（提建议）
- 收到啦～～
- 哎，消息没发出去，再试一下？

避免：

- “你的每一份努力都值得被看见”。
- “我们一起成为更好的自己”。
- “正在接住你的情绪”。
- 任何假装了解对方感受的话。

## 11. 三条完整使用路径

### 路径一：随手分享

魔王开一页「给你看看我现在的桌子」 → 放一张照片 → 小魔王在首页看到这页 → 她补一张自己的照片或回一句话 → 两个人在这页下面接着聊。

### 路径二：一起处理一件事

小魔王在手账里贴一道题或写一句困惑 → 主动点「问小魔丸」 → 看解释、继续问 → 选一段点「给魔王看看」 → 编辑后发成留言 → 魔王回复时回到原手账页。

### 路径三：把一件事记下来

魔王发起「周六晚上，一人挑一首歌？」 → 小魔王答应 → 两个人做完后补照片或一句话 → 觉得这天值得留时，点「收进纪念日」 → 编辑标题和日期 → 创建纪念卡。

## 12. 数据和实现原则

- 留言、手账、约定、纪念日各有自己的数据，但用引用连接，不复制正文。
- 每条内容都记录作者、创建时间和可选附件。
- 发送成功后才清空输入；发送失败保留文字和附件选择。
- 草稿可以保存在当前浏览器。
- 首页的新内容提示表示“有新内容”，不表示在线或已读。
- 旧七夕、旧留言、旧照片和本机信件状态要保持兼容。
- 当前网站沿用现有访问方式；角色按钮只区分署名，不当作身份验证。

## 13. 实施顺序

### 第一阶段：小窝有了门和名字

- 网站名改为魔族小窝。
- 首页、导航和入口改成魔族小窝。
- 当前怪兽正式命名小魔丸，补齐各页的角色状态。
- 上海向助手改为小魔丸通用问答。
- 保留留言板、纪念日和七夕。

### 第二阶段：大魔王小魔王可以一起写

- 创建手账页。
- 双方各自填写文字、图片或语音。
- 页内回复与留言板使用同一条消息。
- 首页显示最近一页和对方新补的内容。

### 第三阶段：小约定和纪念收藏

- 发起、接受、改时间、完成小约定。
- 从手账页创建纪念日。
- 增加小魔丸不同位置的动作与页面细节。

## 14. 验收方式

用两个独立浏览器分别扮演大魔王和小魔王，完成以下检查：

1. 一人发起手账页，另一人能看到、补充、回复；刷新后内容仍在。
2. 一人从问答复制一段内容到留言草稿，编辑并发送；对方回复后能回到原话题。
3. 小约定只有双方答应后才出现在首页；改时间和完成状态能同步。
4. 一页手账可以经确认创建纪念日；七夕和旧留言没有变化。
5. 手机上能看、能写、能上传图片和语音；发送失败时草稿不会丢。
6. 小魔丸没有把真人留言误标成自己的话，也不伪造新消息或对方在线状态。
