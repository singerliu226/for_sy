# 魔丸小助手测评集

这不是“答案像不像人”的主观打分表，而是针对思怡真实使用场景的发布门槛。

## 怎么跑

1. 在测试当天记录当前时间、网络环境和站点版本；同一题连续跑两次，避免用一次偶然结果下结论。
2. 将 `magic-assistant-test-set.json` 的 `history`（如有）与 `prompt` 提交到接口；同时在页面完成一次相同问题的人工可读性检查。
3. 逐条打开来源，记录是否可访问、是否支持回答中的核心结论、是否是官方或当次可用的实时来源。
4. 每题按 5 分制打分，并登记硬失败。只要出现一项硬失败，本轮不得发布。

## 评分原则

- **不对动态事实做死记硬背。** 例如“今晚的末班”“现在营业的药店”只检查回答是否完成当次核验、来源是否支持，而不是期待某个固定店名。
- **来源质量高于来源数量。** 一条当前官方来源优于三条转载或经验帖；经验帖只能辅助说明体验，不能决定安全、医疗、营业、价格和校内规则。
- **先看第一步。** 一个疲惫、晚到或身体不舒服的用户，应在三秒内知道现在先做什么。
- **失败也要可信。** 不能联网时，回退到静态攻略是允许的；把静态内容说成“刚查到”是失败。

## 发布结论

- **可发布：** 满足 JSON 内 `releaseGate`，且 P0 没有硬失败。
- **限范围发布：** P0 全部通过，但 P1/P2 仍有问题；必须在页面提示中保守表达，不宣传为“最新答案”。
- **禁止发布：** 任一硬失败，或成功联网题大量没有可打开来源。
